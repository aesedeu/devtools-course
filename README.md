# Инструменты разработки для ИИ

**Магистратура «Искусственный интеллект», НИУ ВШЭ — 1 курс.**

Фундаментальный курс по инструментарию разработчика: от командной строки до
продакшн-сервиса на FastAPI с базой данных, кэшом, контейнерами и Telegram-ботом.
План: 12 лекций с семинарами, 5 домашних работ.

---

## О курсе

- **Аудитория.** Магистранты 1 курса программы ИИ: сильная математическая и
  ML-подготовка при минимальном опыте в инженерной разработке, DevOps и бэкенде.
- **Цель.** Дать инженерный фундамент, на котором строится любая ML/AI-разработка:
  уверенная работа в Linux, версионирование кода, контейнеризация, сетевое
  взаимодействие сервисов, проектирование и эксплуатация бэкенд-приложения с БД.
- **Формат.** Академический: каждая тема — теория (как оно устроено внутри) плюс
  практика (как этим пользоваться). Упор на внутреннее устройство, а не рецепты.
- **Стек.** Linux, Bash, Git, Docker / Docker Compose, SSH, HTTP / gRPC / WebSocket,
  Python, SQL (PostgreSQL), FastAPI, SQLAlchemy, Redis, aiogram.

## Логика последовательности

1. **Среда (1, 4)** — терминал и автоматизация как базовый навык.
2. **Версионирование (2, 3)** — работать с кодом профессионально.
3. **Контейнеры и сеть (5, 6, 7, 8)** — сначала теория изоляции и протоколов, потом Docker и Compose.
4. **Приложения и данные (9, 10, 11, 12)** — от простого бота к полноценному сервису с БД и кэшем.

Каждый блок готовит соответствующее ДЗ; темы 8–12 напрямую собираются в **ДЗ-5** —
итоговый проект, объединяющий контейнеры, базу данных, API и Telegram-бота.
