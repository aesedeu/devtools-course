# Лекция 6. Контейнеризация и виртуализация

**Материалы:** [конспект](<Контейнеры – verbosed.md>) · [презентация](lecture06-containers.pdf)

## Зачем
Понять, из чего складывается окружение приложения и какие границы задают VM и контейнеры.

## Основные темы
- Окружение, изоляция и воспроизводимость.
- Виртуальная машина, гипервизор и гостевое ядро.
- Контейнер, образ и изменяемые файлы отдельного запуска.
- Монтирование, Docker volume и bind mount.
- Namespaces: видимое окружение; cgroups: учёт и пределы ресурсов.

## Формат
Разбор схем и примеров: два API на одной машине, данные базы после пересоздания контейнера, общий лимит памяти для процессов. Ручные опыты с `unshare` и настройкой cgroups в занятие не входят.

[Прежний семинар](семинар.md) сохранён отдельно как материал с Linux-экспериментами и не входит в текущий маршрут пары.
