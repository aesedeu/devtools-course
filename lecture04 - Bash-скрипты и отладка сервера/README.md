# Лекция 4. Bash-скрипты и отладка сервера

**Материалы:** [презентация](lecture04-bash.pptx) · [семинар](семинар.md)

## Зачем
Автоматизация рутины и умение диагностировать «почему сервер лежит» — базовые навыки эксплуатации.

## Инструменты
bash scripting, `htop`/`top`, `df`/`du`, `journalctl`, `systemd`, `ss`/`netstat`.

## Теория
- Анатомия скрипта: shebang, переменные, кавычки и раскрытие, exit codes.
- Управляющие конструкции: `if`, `for`, `while`, `case`, функции.
- Аргументы, `$@`/`$#`, чтение ввода, работа с текстом.
- Надёжность: `set -euo pipefail`, обработка ошибок, `trap`.
- Планирование: `cron`.
- **Диагностика сервера:** нагрузка CPU/RAM (`top`/`htop`), диск (`df`/`du`), процессы, открытые порты (`ss`), логи (`journalctl`), сервисы (`systemctl`).

## Практика
Написание рабочих скриптов (бэкап, парсинг логов, health-check), отладка через `bash -x`, разбор «падающего» сервера по симптомам.
