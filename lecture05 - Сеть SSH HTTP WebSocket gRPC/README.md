# Лекция 5. Сеть: SSH, HTTP, WebSocket, gRPC

**Материалы:** [конспект](<Сеть – verbosed.md>) · [презентация](lecture05-network.pdf)

## Зачем
Понять, как запрос доходит до программы, и отличать сетевую ошибку от ответа приложения.

## Основные темы
- IP, DNS, порты, сокеты, TCP и UDP.
- HTTP: запрос, ответ, методы, статусы и небольшой API на FastAPI.
- Короткий опрос; обзор долгого опроса, WebSocket и SSE.
- HTTPS и SSH: защищённый канал, проверка сервера и ключи пользователя.

## Практика
Локальный файловый сервер, запросы через `curl`, чтение и изменение значения API, короткий опрос. Вход по SSH требует заранее подготовленного сервера.

В дополнительных разделах конспекта: готовый пример gRPC, фильтрация соединений, проброс портов и передача файлов. [Прежний семинар](семинар.md) содержит отдельные примеры с внешними сервисами и не является продолжением команд конспекта.
