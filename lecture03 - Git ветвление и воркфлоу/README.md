# Лекция 3. Git: ветвление и воркфлоу

**Материалы:** [презентация](lecture03-git-vetvlenie.pdf) · [семинар](семинар.md)

## Зачем
Реальная разработка — командная. Нужно уметь вести параллельную работу и аккуратно её сливать.

## Инструменты
git branch/merge/rebase, GitHub PR, code review.

## Теория
- Ветки как дешёвые указатели; создание/переключение.
- **Merge vs Rebase:** fast-forward, 3-way merge, что делает rebase и когда он опасен («золотое правило rebase»).
- Конфликты слияния: почему возникают, как читать и разрешать.
- Модели ветвления: Git Flow, GitHub Flow, trunk-based.
- Pull/Merge Requests, code review, защита веток.
- Полезное: `stash`, `cherry-pick`, `reset` (soft/mixed/hard), `revert`, reflog как «спасательный круг».

## Практика
Ветвление и слияние, провокация и разрешение конфликта, rebase-переписывание истории, полный цикл feature-branch → PR → merge на GitHub.
