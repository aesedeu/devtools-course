# Лекция 1. Linux и командная строка

**Материалы:** [презентация](lecture01-linux.pdf) · [семинар](семинар.md)

## Зачем
Вся ML/AI-инфраструктура живёт на Linux. Без уверенной работы в терминале дальше двигаться невозможно.

## Инструменты
bash, coreutils (`ls`, `cd`, `cp`, `mv`, `rm`, `cat`, `grep`, `find`, `sed`, `awk`), пайпы и редиректы, `man`.

## Теория
- Устройство ОС: ядро vs userspace, что такое shell.
- Файловая система Linux: FHS (`/`, `/etc`, `/var`, `/home`, `/proc`), inode, ссылки (hard/soft).
- Права доступа: rwx, пользователи и группы, `chmod`/`chown`, sudo.
- Процессы: PID, дерево процессов, сигналы, foreground/background.
- Потоки ввода-вывода: stdin/stdout/stderr, пайплайны, редиректы.
- Переменные окружения, `PATH`, конфигурация shell (`.bashrc`).

## Практика
Навигация по ФС, работа с файлами и правами, композиция утилит через пайпы, поиск и фильтрация текста (`grep`/`find`), управление процессами, менеджеры пакетов (`apt`).
